# sdi-project-1

Crypto Terminal is a free Crypto Currency dashboard that works with the Coinlore API.

You can build a watchlist by typing in a ticker and adding it to your list and remove items by clicking them.

There is an Asset Profile Analytics section to look at assets price, global rank, % change in 24 hours, market cap, and supply.

In the middle section there is a Global Market Metrics section for a total market overview. And, on the right is a Top 20 Leaders and Top 20 Losers that have the highest percent change per section.

To install:
    Fork and clone the repository
    npm init -y
    npm install live-server
    add:
        "start": "live-server" to scripts object
    start the local environment with: npm start
